# One Resume

One Resume is a resume version tracker. You keep one main resume and pull from it
to build resumes tailored to each job.

## MVP features

- **PDF import:** upload a PDF of your resume or CV to fill in the main resume.
- **Tailored resumes:** create a copy of the resume for a role you're applying to.
  Each copy stores details about that role, taken from the job description or
  entered by hand.
- **Diffs:** compare a tailored resume with the main resume.
- **Promote changes:** copy edits made in a tailored resume back to the main resume.
